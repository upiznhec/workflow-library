# Social Media AI Workflow Library

Prototype website for a DSM 596 capstone project at USC: tested AI workflows for social media managers and creators, with step-by-step setup guides.

Live page: https://upiznhec.github.io/workflow-library/

Workflow 2 ("Turning trend sources into a topic list") is adapted from [Sibyl System Hotspot Monitor](https://github.com/liray0919/Sibyl-System-Hotspot-Monitor) by Misaka Studio (MIT License), used with the author's permission. Not for commercial use.

`index.html` is generated by the project's build script. Edit the source and rebuild rather than editing this file.
